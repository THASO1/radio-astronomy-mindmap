# 🌌 CosmicNotes — Interactive Radio Astronomy Mind Map

**Explore radio astronomy through an interactive mind map, guided study mode, and knowledge quizzes.**

[🚀 Live Demo](https://radio-astronomy-mindmap.vercel.app/) · [📦 GitHub Repository](https://github.com/THASO1/radio-astronomy-mindmap)

---

## ✨ Overview

CosmicNotes is an interactive learning experience designed to make radio astronomy concepts easier to explore, understand, and review.

Instead of navigating static lecture notes, learners can explore connected concepts, reveal deeper explanations, study key ideas, and test their understanding through quizzes — all in a dark, astronomy-inspired interface.

## 🚀 Features

- **Interactive Mind Map** — Explore the main topics and their connected concepts.
- **Focused Exploration** — Reveal relevant child concepts when hovering over a topic.
- **Deeper Concept Expansion** — Dive into additional layers of selected concepts.
- **Concept Details** — Select nodes to explore their associated information.
- **Study Mode** — Review concepts in a dedicated study experience.
- **Interactive Quiz** — Answer questions, receive feedback, and track your results.
- **Progress Tracking** — Keep track of quiz attempts and best scores.
- **Responsive Interface** — Designed to work across desktop, tablet, and mobile screen sizes.
- **Astronomy-Inspired Design** — A dark visual theme built around exploring scientific ideas.

## 🪐 Topics Covered

The mind map explores topics including:

- Radio Astronomy
- Discovery of Interstellar Hydrogen
- Atomic Hydrogen and the 21-cm Line
- Radio Telescopes and Signal Processing
- Mapping the Hydrogen Sky
- Doppler Effect and Galactic Motion
- Hydrogen and Galaxy Structure
- Weighing Galaxies and Dark Matter

## ⚡ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) — A current supported version
- npm — Included with Node.js
- Git

### Installation

Clone the repository:

```bash
git clone https://github.com/THASO1/radio-astronomy-mindmap.git
cd radio-astronomy-mindmap
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL printed in your terminal to explore the application.

### Production Build

Create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🎯 How to Explore

1. Open the [live application](https://radio-astronomy-mindmap.vercel.app/).
2. Explore the main concepts in the mind map.
3. Hover over a topic to reveal its direct connections.
4. Select a concept to inspect its details.
5. Use the available controls to explore deeper concepts.
6. Switch to **Study Mode** to review the material.
7. Enter **Quiz Mode** to test your understanding and review your results.

CosmicNotes combines scientific learning with visual exploration. Its dark astronomy-inspired interface keeps the focus on connected ideas, while interactive expansion lets learners move from an overview into more detailed concepts at their own pace.
